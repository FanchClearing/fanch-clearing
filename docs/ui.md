# UI 정리: 팬 응원 대결

구현 요청서(기능·단계·완료 기준)를 바꾸지 않고, 그 위에 얹는 화면과 연출만 적는다.
서버가 보내는 값은 요청서에 있는 것(상태, 팀별 인원, 팀별 점수)만 쓴다. 아래 연출은 전부 그 값의 변화량으로 클라이언트가 만든다.

## 1. 공통 톤: 키치한 픽셀

- 느낌: 8비트 오락실 대전 게임.
- 픽셀 규칙
  - 모서리는 전부 직각, 테두리는 검정 4px, 그림자는 번짐 없이 4px 어긋난 단색.
  - 그라데이션과 부드러운 전환을 쓰지 않는다. 움직임은 `steps()`로 뚝뚝 끊기게 한다.
  - 그림은 `image-rendering: pixelated`로 확대한다.
- 폰트: 한글 픽셀 폰트 하나로 통일한다. 1순위 Galmuri11, 2순위 둥근모꼴. CDN 로드는 구현 때 확인하고, 실패하면 기본 고정폭 폰트로 떨어진다.
- 색 (CSS 변수로 분리해서 실제 구단 색으로 바꿀 수 있게 한다)

| 용도 | 색 | 비고 |
|---|---|---|
| 배경 | 짙은 남색 `#14121f` | 원색이 튀도록 어둡게 |
| A팀 | 핫핑크 `#ff3d7f` | 항상 왼쪽 |
| B팀 | 시안 `#23d5ff` | 항상 오른쪽 |
| 강조 | 노랑 `#ffd23f` | 상태 배지, 승리 발표 |
| 클리어링 경고 | 노랑×검정 사선 줄무늬 | 팀 색과 겹치지 않게 빨강은 쓰지 않는다 |

- 팀은 색만으로 구분하지 않는다. 세 화면 모두 A는 왼쪽, B는 오른쪽이고 글자 `A` / `B`를 같이 적는다.
- 팬 화면은 배경에 내 팀 색을 어둡게 깔아서 자기 팀을 화면 전체로 알 수 있게 한다.

## 2. 공통 부품

### 2.1 밀어내기 바

세 화면에 모두 들어가는 핵심 부품이다. 가로로 긴 막대의 왼쪽을 A색, 오른쪽을 B색으로 채우고, 두 색이 만나는 경계가 우세한 쪽에서 열세한 쪽으로 밀려 들어간다.

- 경계 위치 = A점수 ÷ (A점수 + B점수). 0:0이면 정확히 가운데.
- 한쪽이 화면에서 사라지지 않도록 15%~85% 사이로만 움직인다.
- 서버 값이 올 때마다(0.5~1초) 한 번씩 "툭" 밀린다. 목표 지점을 살짝 지나쳤다가 돌아와서 밀치는 느낌을 준다.
- 긴장감 떨림: 경계가 좌우로 계속 떤다. 떨림 폭은 직전 갱신에서 두 팀이 올린 점수 합에 비례한다(2~6px). 아무도 안 흔들면 멈춘다.
- 접전(45%~55%)이면 떨림을 키우고 경계에 충돌 스파크를 띄운다.
- 바 양 끝에 팀 점수를 크게 적고, 점수가 오르면 숫자가 한 번 튄다.
- 응원 상태에서는 응원 점수, 클리어링 상태에서는 싸움 점수를 기준으로 그린다. 클리어링이 시작되면 가운데에서 다시 시작하고, 응원 바는 작게 줄어든 채 멈춰 있다가 클리어링이 끝나면 이전 위치 그대로 돌아온다.

### 2.2 떠오르는 파티클 (인스타 라이브 하트)

- 흔들림 1회(또는 debug "흔들기" 버튼 1회)마다 팬 화면 오른쪽 아래에서 1개가 생긴다.
- 1.2~1.8초 동안 좌우로 흔들리며 위로 올라가다 사라진다. 크기(16~32px), 좌우 폭, 속도는 매번 조금씩 다르다.
- 모양: 응원 상태는 픽셀 하트·야구공·응원봉, 클리어링 상태는 주먹·별·충돌 표시. 색은 내 팀 색.
- 전광판에서는 팀 점수가 늘어난 만큼 왼쪽 가장자리에서 A색, 오른쪽 가장자리에서 B색 파티클이 올라온다.
- 개수 제한: 팬 화면 동시 30개, 전광판 팀당 동시 40개, 갱신 한 번에 팀당 최대 8개. 넘치면 버린다.
- 점수가 인정되지 않는 상태(대기, 종료)에서는 나오지 않는다.

### 2.3 실시간 인원 (인터넷 방송 시청자 수)

팀 하나를 방송 방 하나처럼 보여 준다.

- 팀 이름 옆에 깜빡이는 `● LIVE` 점, 사람 아이콘, 인원 숫자.
- 숫자가 바뀌면 한 자리씩 굴러서 바뀌고, 옆에 `+1` / `-1`이 잠깐 튀어오른다.
- 인원이 더 많은 방에 왕관을 붙인다. 같으면 없다.
- 전광판에만 입장 알림을 띄운다. 인원이 늘면 `A팀 팬 1명 입장!` 한 줄이 아래에서 올라와 3초 뒤 사라진다. 퇴장은 숫자만 줄이고 알림은 없다.

## 3. 팬 화면 (휴대폰, 세로)

### 3.1 팀 선택

- 화면을 좌우로 나눠 왼쪽 A색, 오른쪽 B색의 큰 버튼 두 개.
- 고르면 고른 쪽이 넓어지고 반대쪽은 어두워진다. 다시 눌러 바꿀 수 있다.
- 아래에 "참여하기" 버튼. 팀을 고르기 전에는 비활성. 누르면 센서 권한을 요청하고 입장한다.
- 권한을 거부하면 입장은 시키되, 대결 화면 상단에 "센서 권한이 없어 흔들기가 집계되지 않습니다"를 계속 띄운다.

### 3.2 대결 화면

```
┌────────────────────────┐
│ [ 응원 중 ]            │  상태 배지
│ A ●LIVE 12    B ●LIVE 9│  인원 (내 팀에 MY 표시)
│ A ████████⚡░░░░░ B    │  밀어내기 바
│ 1204              980  │  팀 점수
│                        │
│        내 점수         │
│          37            │  가장 큰 숫자        ♥
│     흔들어라!          │  상태별 한 줄 안내     ♥
│                        │                      ♥
│ [ 흔들기 ]             │  ?debug=1 일 때만
│ [ 팬치클리어링 요청 ]  │  5단계, 응원 상태에서만
└────────────────────────┘
```

- 내가 흔들면: 화면 전체가 2~4px, 0.08초 흔들리고, 파티클 1개가 올라가고, 내 점수가 바로 +1 된다. 쉬지 않고 흔들수록 흔들림 폭이 최대 8px까지 커진다.
- 내 점수와 파티클은 서버 응답을 기다리지 않고 바로 반응한다. 팀 점수와 밀어내기 바는 서버 값만 따른다. 서버 상한에 걸려 깎인 점수는 다음 응답에서 내 점수가 서버 값으로 맞춰진다.
- 상태가 바뀌면 화면 전체를 덮는 배너가 1.5~3초 뜬다. 문구: 경기 시작 / 벤치클리어링 발생 / 벤치클리어링 종료와 라운드 승패 / 경기 종료와 승패.

### 3.3 상태별 모습

| 상태 | 배경 | 한 줄 안내 | 흔들었을 때 |
|---|---|---|---|
| 대기 | 내 팀 색(어둡게) | 곧 시작합니다 | 반응 없음 |
| 응원 | 내 팀 색(어둡게) | 흔들어라! | 화면 흔들림 + 하트 파티클 |
| 클리어링 | 노랑×검정 경고 줄무늬 테두리, 배경 반전 | 싸워라! | 화면 흔들림(더 크게) + 주먹 파티클 |
| 종료 | 승리: 노랑 / 패배: 회색 / 무승부: 내 팀 색 | 승리! · 패배… · 무승부 | 반응 없음 |

## 4. 전광판 화면 (큰 화면, 가로)

```
┌───────────────────────────────────────────────────────┐
│ [ 응원 중 ]                                           │
├────────────────┬───────────────────┬──────────────────┤
│ A팀  ●LIVE 12  │                   │  B팀  ●LIVE 9    │
│                │    QR / 무대      │                  │
│     1204       │                   │      980         │
├────────────────┴───────────────────┴──────────────────┤
│ A ████████████████████⚡░░░░░░░░░░░░░░░ B             │
│ A팀 팬 1명 입장!                                      │
└───────────────────────────────────────────────────────┘
```

가운데 칸은 상태에 따라 바뀐다.

| 상태 | 가운데 칸 |
|---|---|
| 대기 | QR을 가장 크게. 아래에 "QR을 찍고 팀을 고르세요" |
| 응원 | QR은 구석으로 줄여서 남긴다(늦게 온 사람 입장용). 밀어내기 바와 점수가 주인공 |
| 클리어링 | 픽셀 선수들이 싸우는 무대. 싸움 점수 바 |
| 종료 | 승리 팬 발표. 응원 점수 최종 값 |

## 5. 벤치클리어링 연출

순서대로 일어난다.

1. 0초: 화면이 흰색으로 2~3번 깜빡인다(초당 3회 이하). `navigator.vibrate`가 있는 기기는 진동도 같이 울린다. 위아래에서 경고 줄무늬 띠가 들어온다.
2. 0.3초: "벤치클리어링 발생!!" 글자가 크게 찍힌다.
3. 0.8초: 왼쪽에서 A색 유니폼 선수 3~4명, 오른쪽에서 B색 선수 3~4명이 달려 나와 가운데에서 부딪힌다. 부딪힌 자리에 만화식 싸움 먼지구름이 생기고 별과 주먹이 튀어나온다.
4. 진행 중: 먼지구름이 싸움 점수 바의 경계 위에 올라타서, 우세한 팀 쪽에서 열세한 팀 쪽으로 밀려간다.
5. 종료: 구름이 걷힌다. 이긴 팀 선수는 만세, 진 팀 선수는 쓰러져 머리 위에 별이 돈다. 무승부면 양쪽 다 주저앉는다. "라운드 승리: A팀 팬!"을 3초 보여 준 뒤 선수들이 퇴장하고 응원 상태로 돌아간다.

- 전광판은 가운데 칸 전체를 무대로 쓴다. 팬 화면은 밀어내기 바 자리에 같은 장면을 작게 넣는다.
- 선수 그림은 16×16 한 종류만 만들고 유니폼 색만 팀 색으로 바꿔 좌우 반전해서 쓴다. 이미지 파일 없이 코드로 그린다.
- 동작은 달리기 2장, 주먹질 2장, 만세 1장, 쓰러짐 1장.
- 팬치클리어링(5단계)은 같은 연출에 문구만 "팬치클리어링"으로 바꾼다.

## 6. 운영자 화면

꾸미지 않는다. 공통 폰트와 색만 따르고, 잘못 누르지 않는 것이 우선이다.

- 맨 위에 현재 상태를 크게.
- 그 아래 양 팀 인원과 점수(응원, 싸움), 밀어내기 바.
- 버튼은 휴대폰에서도 누를 수 있게 크게, 한 줄에 하나씩: 경기 시작 / 벤치클리어링 시작 / 벤치클리어링 종료 / 경기 종료 / 초기화.
- 5단계에서 "팬치클리어링 시작" 버튼과 요청 수(`3 / 5`)를 추가한다.
- 누를 수 없는 버튼은 회색으로 죽인다. 지금 누를 수 있는 버튼만 노랑.

## 7. 구현 단계에 얹는 순서

요청서는 "디자인 완성도 작업"을 만들지 않는 것으로 적고 있다. 이 문서의 연출은 그 예외이므로, 각 단계의 완료 기준을 먼저 통과시킨 뒤에 얹는다.

| 단계 | 같이 넣는 것 |
|---|---|
| 1 뼈대 | 색 변수, 픽셀 폰트, 테두리·그림자 규칙 |
| 2 입장과 인원 | 팀 선택 화면, 실시간 인원(LIVE 숫자, 입장 알림) |
| 3 응원 대결 | 밀어내기 바, 파티클, 화면 흔들림, 승리 발표 |
| 4 벤치클리어링 | 경고 줄무늬, 깜빡임·진동, 문구, 픽셀 선수 연출 |
| 5 팬치클리어링 | 문구 교체, 요청 수 표시 |

시간이 모자라면 아래 순서로 뺀다: 선수의 만세·쓰러짐 동작 → 입장 알림 → 숫자 굴림 → 접전 스파크 → 왕관.
